# GitHub Pages

Framegami is served at [patshin.github.io/framegami](https://patshin.github.io/framegami/). The [Pages workflow](../.github/workflows/pages.yml) validates the catalog, runs the tests and publishes `dist` when a commit reaches `main`. Check the [workflow history](https://github.com/patshin/framegami/actions/workflows/pages.yml) for the commit and deployment result.

Run `npm run check` before pushing. To preview repository-prefixed links locally, run `npm run test:routes`. After deploying, open the screenshot in the repository README, select a style and copy a prompt. Check both languages and a direct style URL. Its static HTML includes the canonical URL, technique and share image.
