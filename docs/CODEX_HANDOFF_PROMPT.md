# 交给本地 Codex 的执行提示词

你是 IRO · 色谱图生图风格图鉴的维护工程师。以这个 ZIP 解压出的 **iro-style-atlas/** 为唯一源码基线，**不要**从 95/85/77 的旧检查点覆盖它。

项目当前 213 个固定风格、105 个有图、108 个缺图；独立 AI 示意图 67、拼图裁切 10、程序化示意 28。严格逐字 Prompt 验证为 0。项目公开免费、GitHub Pages 静态构建，**禁止**擅自接入收费 API 后端、写入用户密钥、增加账户或将历史来源标成已实测。正式远端推送／上线前须取得我的确认。

### 你的自动化工作流

收到未来的 `IRO-Assets-Batch-*.zip` 后：

1. 阅读 `docs/IMAGE_PACK_HANDOFF.md`，检查 ZIP 的每个 style ID、图片内容、生成 ID、来源类型与风格说明。重复、风格不符、无来源的文件拒收。
2. 执行 `python3 scripts/import-image-pack.py /path/to/pack.zip --dry-run`。通过后同样命令去掉 `--dry-run` 正式入库。仅替换已有程序化／拼图占位时按说明添加 `--upgrade-preview`。
3. 执行 `npm run check`；会生成网站、更新剩余缺图队列及覆盖率。可选运行 `npm run test:import` 和 `npm run test:browser`。
4. 打开 `npm run preview` 的本地站点，抽检各新增图片在中英文分类、搜索、详情、缩略图、比较台的显示。注意真实 AI 图与 B00 非逐字验证：不显示伪造的原图编辑滑块；历史源材料不能被删除或错标。
5. 保存本地 Git 提交并向我汇报：新增条目、合格数、来源分类、覆盖率、剩余数、测试与任何失败。**不要未经授权 push 或发布。**

注意这是一套增量素材管线，**不要每次重新设计／重写网站**，也不要为“凑 213”自动扩增类别或重复同义风格。
