# IRO · 色谱 v0.2

Date: 2026-10-19

## v0.2 新增与修复 / Changes

1. **按任务类型筛选**：202 条保留结构的主馆配方、11 条允许重构的实验室配方。分类／家族／关键词与转换类型可组合。
2. **批量带走配方**：导出当前筛选结果或比较台选集为 Markdown；状态逐条标注，不假装已测。
3. **导入导出闭环**：本站导出的 `iro-recipe/v1` 能导回为私人副本；兼容 v1 备份，重复冲突保留两份。
4. **自定义编辑与标签**：最多 12 个纯文本标签；保存当前条目与另存副本分开，备份保留标签。
5. **比较链接**：真正的 HTTP 部署下，链接保留 2–4 项选择、模型与提示词语言。单文件预览不伪造公共链接，可导出比较配方。
6. **例图隔离**：详情和比较只使用当前模型、语言、Prompt 版本的合格例图。不能将 ChatGPT 英文样例展示成 Gemini 或中文 Prompt 已测。
7. **持久化失败兜底**：一次存储失败不再跳过后续字段；当前会话仍保留草稿，并提示导出，不用“已持久保存”覆盖故障提示。
8. **导航与 404**：保留 Cmd/Ctrl 点击行为、减少动态效果偏好；深层 404 自包含，不依赖错误的相对脚本路径。构建按 GitHub 仓库名计算 404 返回路径。
9. **真实 HTTP 检查**：新增根路径、仓库前缀、内容类型、重定向、HEAD、404、405 与路径边界检查。它们是 Node HTTP 验证，不是被禁止的浏览器导航的替代声明。
10. **发布防误操作**：确认 HTTP 404 后才允许进入新建步骤；已有仓库、403、网络异常、取消均停止。新版工作流与官方资料核对过，但未实际远端运行。
11. **内容发布门禁**：独立 B00 或任何 ChatGPT 例图缺失时，正式内容门禁必须失败；研究预览可以显式检查通过。

风格草案仍是 213 条；本次没有通过重复风格或语言版本提高风格数。
